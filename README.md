# CampusConnect

## Project Overview
CampusConnect is a web application designed to help college students discover campus events, explore activities, and stay connected with their university community. The platform provides a centralized location where students can find events that match their interests.

## Problem Statement
Students often miss campus activities because event information is scattered across different platforms. CampusConnect aims to make event discovery easier by bringing campus events together in one accessible platform.

## Main Features
- Browse campus events.
- Create, edit, and delete events.
- Search events by name.
- Filter events by category.
- View detailed event information.
- Receive personalized AI-based event recommendations.
- View explanations for recommended events.

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Python and Flask
- Database: SQLite
- Testing: Pytest
- CI/CD: GitHub Actions

## AI Integration
The project plans to use AI-based recommendation functionality to help students discover events based on their interests and preferences. Recommendations will include explanations to help users understand why particular events are suggested.

## Project Management
Development is organized into two sprints using Jira. The project backlog includes epics, user stories, and subtasks.

## Project Goal
The goal of CampusConnect is to improve student engagement, simplify campus event discovery, and help students become more involved in university life.
